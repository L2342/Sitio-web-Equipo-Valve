# Steam · Sistema Integrado de Gestión — Valve Corporation

Sitio web del proyecto académico (Grupo 03) sobre Steam, la tienda digital y plataforma de distribución de videojuegos de Valve para Windows, Mac y Linux.

## Contenido
- `index.html` — página principal (abrir en el navegador)
- `img/` — ilustraciones de videojuego del sitio
- `docs/` — versiones web de los documentos (imágenes, miniaturas y HTML)
- `originales/` — los 24 documentos originales del proyecto (PDF, Word, Excel, imágenes, HTML)

## Publicar con GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio (con `index.html` en la raíz).
2. En el repositorio: **Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save**.
3. En 1–2 minutos el sitio queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
